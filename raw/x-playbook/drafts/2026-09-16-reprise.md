Ce soir j'avais six conversations Claude Code ouvertes en même temps.

J'étais incapable de dire laquelle travaillait.

Pour savoir ce qu'une session avait fait, je devais la relire en entier. L'une d'elles avait été vidée. Elle a reconstitué sa journée en lisant les commits git.

J'ai écrit Reprise pour ça. En local, sur le port 8920.

Un mur de fenêtres, une par session vivante. Le fil se rafraîchit toutes les 5 secondes.

Le fil ne garde que les actions : mes messages, et les Edit, Bash, Read, Grep de la session. La prose de l'assistant est écartée côté serveur. Elle noyait ce qui se passait.

Chaque conversation porte une fiche générée par Haiku depuis son transcript : fait, en train, demandé pas encore fait. Une fiche toutes les 3 minutes. Consigne dure dans le prompt : rien d'inventé, rien de déduit.

Chaque fenêtre a une barre de saisie qui envoie vraiment dans la session. Le protocole est documenté par le binaire claude dans ses propres logs : une socket Unix, du JSON ligne par ligne.

Un onglet Stats pour les tokens. Les relectures de cache y sont comptées à part. Elles pèsent 96 % du brut : sans ce tri j'affichais 1 milliard de tokens là où 42 millions avaient réellement été traités.

L'indexeur lit 2,66 Go de transcripts en 7 secondes au premier passage.

Rien ne sort de l'ordinateur. Le serveur n'écoute que sur 127.0.0.1.
