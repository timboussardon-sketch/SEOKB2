# Bootcamp 5 : programme jour par jour

Séquence des messages envoyés aux participants du bootcamp 5 (dashboard `organikk.co/dashboard-bootcamp-organikk-private-2026/?bootcamp5`). Texte intégral : `raw/bootcamp5/programme-messages-jour-par-jour.md`. Suivi 1:1 assuré avec Manda. Le dashboard a un onglet par étape ; toute modif d'onglet se reporte sur bootcamp 4 et les espaces accompagnement (voir [[methodes/dashboard-suivi-client-bootcamp]] et [[methodes/bootcamp-dupliquer-un-projet]]).

| Jour | Thème | Action du jour | Onglet dashboard |
|---|---|---|---|
| J1 | Démarrage | Regarder la vidéo, remplir les 3 questionnaires (les 3 docs fondamentaux pour personnaliser le système) | Documents |
| J2 | Cas client | Vidéo n°2, remplir les 4 champs (client/site, offre principale, cible, objectif business), objectif à 30 jours | Vidéo, Cas client (depuis Mon profil) |
| J3 | Installation | Vidéo n°3, 6 étapes d'installation du dataset SEO, envoyer le premier message (étape 6) | Vidéo, Installation |
| J4 | Skills mots-clés | Tester quelques skills sur un cas client ou son site, noter les remarques. Workflow 1 | Mots-clés |
| J5 | Call collectif 9h | Présentation 45 min puis questions/réponses (1h15 à 1h30 prévues) ; questions à noter avant | n/a |
| J6 | Terminal + Claude + Obsidian | Connecter les trois, versions Mac et Windows | Vidéo, Tech → Obsidian |
| J7 | Tester le système | Lancer une tâche depuis le Terminal ; vérifier déclenchement du skill, usage des données client, exploitabilité ; générer un prompt de correction | Vidéo, Mise en pratique |
| J8 | Audits | Pré-audit (contexte client, problèmes du site) et audit complet | Audit |
| J9 | Exploiter l'audit | 3 problèmes prioritaires justifiés, plan d'action 30 jours, dashboard HTML client, email en brouillon Gmail à valider | Audit |
| J10 | Connecter la GSC | Prompt d'installation de l'API GSC, liste des sites et CSV 90 jours d'un site. Objectif : 0 hallucination dans les recos | Tech → GSC API |
| J11 | Rédaction IA | Workflow complet et skills : briefs, structure Hn. Calls 1:1 proposés, call collectif la semaine suivante | Rédaction |
| J12 | Dupliquer un vault | Créer un vault client par duplication | Duplication (dernier onglet) |
| J13 | Préparer les automatisations | Étape 1 : répondre aux questionnaires ; étape 2 (lendemain) : soumettre au Terminal | Automatisation |
| J14* | Créer une automatisation | Choisir une tâche (rapport de position, mini audit), forcer le Terminal à créer une tâche programmée qui fonctionne, MP ensuite | Automatisation |
| J15* | Automatisations prêtes à l'emploi + MAJ sans ZIP | Récupérer les automatisations des 30+ consultants ; mise à jour via « Il y a une mise à jour du système ? Si oui, installe-la. » | Automatisations → Automatisations déjà construites ; MAJ |

\* J14 et J15 ne sont pas numérotés dans la source ; numérotation déduite de l'ordre des messages.

Rendez-vous cités : point vers 15h aux jours 2 et 3, call collectif à 9h au jour 5, discussion en fin d'après-midi aux jours 6, 8 et 9.

[MATIÈRE MANQUANTE] : dates calendaires de chaque jour, heures des horaires 1:1 proposés au jour 12 (liste absente de la source), contenu des vidéos.
