# MediaSEO - 2026-10-07

## OpenAI publie le 7 octobre 2026 le déploiement de GPT-6 dans l'onglet Chat de ChatGPT, assorti d'une interface « Intelligent UI » qui compose la mise en page de chaque réponse

OpenAI publie le 7 octobre 2026 une page intitulée « GPT-6 and Intelligent UI for Everyone » (openai.com/index/gpt-6-for-everyone), reprise par Matt G. Southern (Search Engine Journal) le même jour. L'onglet Chat de ChatGPT bascule sur GPT-6 Sol pour les comptes Plus, Pro, Business et Enterprise, et sur GPT-6 Luna pour les comptes Free et Go à partir du lendemain. L'option « Latest » est remplacée par GPT-6, GPT-5.6 Sol reste disponible séparément, les comptes Pro conservent GPT-6 Astra, et le niveau Edu dépend de la configuration administrateur. L'Intelligent UI applique une mise en page générée pour chaque réponse, pouvant inclure boutons, formulaires, graphiques et comparaisons, ou rester en texte brut. OpenAI publie que l'utilisateur peut demander « create a tool for the task at hand ». Un réglage « Layout and visuals » permet de réduire les éléments visuels. Mesure publiée par OpenAI sur les requêtes nécessitant une recherche web : GPT-6 Instant commence à répondre 44 % plus vite que GPT-5.6 Instant en moyenne. L'Intelligent UI se déploie progressivement sur le web et les applications à jour, pour les niveaux de réflexion d'Instant à Extra High. GPT-6 Sol et Luna avaient été lancés le 22 septembre 2026 dans Codex, ChatGPT Work et l'API, sans accès au Chat.

**Limites.** OpenAI ne publie pas de chiffre d'échantillon pour la mesure de latence de 44 %, ne détaille pas la méthodologie, et ne publie pas de calendrier d'arrivée sur Pro (toujours sur Astra) ni sur les anciennes applications bureau macOS et Windows. L'affichage des citations dans les graphiques, comparaisons ou outils générés par l'Intelligent UI n'est pas documenté dans l'annonce consultée. Les « Sources » restent accessibles via un bouton quand il est disponible, sans spécification de couverture.

Southern, 7 octobre 2026 - https://www.searchenginejournal.com/chatgpt-gpt-6-intelligent-ui/592249/

## WordPress.org publie le 2 octobre 2026 la version 0.7.0 du plugin « MCP Adapter » reliant l'Abilities API de WordPress au protocole MCP, 40 000 installations actives

Le dépôt officiel wordpress.org/plugins/mcp-adapter affiche la version 0.7.0 publiée le 2 octobre 2026, avec plus de 40 000 installations actives et pour contributeurs Ovidiu Galatan et David Levine. Description publiée : le plugin « bridges WordPress's Abilities API with the Model Context Protocol (MCP) specification ». Search Engine Journal publie le 7 octobre 2026 un article signé Roger Montti rapportant que le plugin était antérieurement distribué via les releases GitHub du dépôt WordPress/mcp-adapter avant son arrivée dans le dépôt officiel. Jason Adams, Director of AI Engineering chez Automattic, publie sur X : « This is the canonical MCP plugin for WordPress » et « It makes use of the Abilities API to avoid functional redundancy while handling authorization ». Le protocole MCP (Model Context Protocol) est un standard ouvert développé par Anthropic pour la connexion entre systèmes d'IA et sources de données. L'Abilities API de WordPress est une interface commune pour exposer des fonctionnalités du CMS à des systèmes externes. Le plugin se présente comme compatible avec les versions successives de MCP.

**Limites.** WordPress.org ne publie ni la liste précise des Abilities exposées via le plugin ni le périmètre fonctionnel accessible aux agents IA connectés. L'article Search Engine Journal n'identifie pas l'éditeur formel du plugin au-delà du dépôt WordPress.org et du relais Automattic. Aucune mesure de volumétrie d'usage réel (requêtes MCP par jour, agents connectés) n'est publiée. Le plugin reste en pré-version 1.0 selon le numéro affiché.

**Sources.** WordPress.org, page du plugin « MCP Adapter » version 0.7.0, dernière modification 2 octobre 2026 - https://wordpress.org/plugins/mcp-adapter/ · Search Engine Journal, Roger Montti, 7 octobre 2026 - https://www.searchenginejournal.com/wordpress-releases-canonical-mcp-adapter-plugin/592159/ · Jason Adams (@jasontheadams), post X cité par Search Engine Journal

## Trellner Research publie le 2 septembre 2026 une étude mesurant que trois sites apparentés totalisent 215 128 pages « best software » générées, dont le modèle sonar de Perplexity cite une partie dans ses réponses

Trellner Research publie le 2 septembre 2026 le rapport TR-2026-009 « Manufactured Sources Behind AI Recommendations » (trellner.com/reports/manufactured-sources-behind-ai-recommendations). Instantané mesuré le même jour, sur les classements Tranco du 1er septembre 2026. Chiffres publiés : trois sites (worldmetrics.org, wifitalents.com, gitnux.org) totalisent 215 128 pages « best <catégorie> » générées, réparties 70 731 / 71 684 / 72 713. Protocole publié : 380 catégories logicielles rédigées avant toute observation, interrogation des modèles sonar et sonar-pro de Perplexity via OpenRouter, 760 appels au total. Résultats publiés : 7 534 citations retournées pointant vers 2 055 domaines distincts ; 59,8 % des citations pointent vers des domaines classés au-delà du 100 000e rang Tranco, 23,4 % vers des domaines absents du top un million ; les trois sites « best list » totalisent 181 citations (2,4 %) dans 41 catégories ; guideflow.com cité 194 fois dans 96 catégories, Wikipédia cité 3 fois. La propriété commune des trois sites est inférée publiée par les auteurs à partir de l'infrastructure (nameservers Cloudflare, gabarits identiques, dates d'enregistrement de décembre 2023 à mai 2024), aucun ne nomme publiquement de propriétaire. Verbatim publié : « Grounding is not a term buyers use ». Les auteurs publient le jeu de données, les scripts et la méthode sous licence CC BY 4.0.

**Limites.** L'étude mesure Perplexity sonar et sonar-pro uniquement, sans ChatGPT, Gemini, Copilot ni Google AI Mode. Les deux modèles Perplexity partagent la même couche de recherche (chevauchement de 0,898, citations identiques dans 289 catégories sur 380), ce qui réduit l'indépendance des mesures. Les 380 catégories ont été rédigées par les auteurs et ne constituent pas un échantillon représentatif des requêtes réelles. Les récupérations de pages ont été faites via un proxy rotatif sous un user-agent de recherche identifié, pouvant différer de ce que voit un crawler Perplexity réel. L'étude ne teste pas si la suppression de ces sources modifierait les recommandations.

**Sources.** Trellner Research, rapport TR-2026-009 « Manufactured Sources Behind AI Recommendations », 2 septembre 2026 - https://trellner.com/reports/manufactured-sources-behind-ai-recommendations/

**Illustration suggérée.** Capture du rapport trellner.com matérialisant le chiffre « 215,128 pages » et la liste des trois domaines worldmetrics.org / wifitalents.com / gitnux.org, ou graphique publié de la distribution Tranco des 7 534 citations retournées par sonar/sonar-pro.

## La stat du jour

**Ahrefs publie le 6 octobre 2026 sur ahrefs.com/blog/how-to-measure-ai-search-visibility sous la signature de Louise Linehan, Content Marketer chez Ahrefs, revue par Ryan Law, un article mesurant que 6 % des visiteurs issus de la recherche IA sur wordcount.com s'inscrivent au produit Ahrefs Free, soit un taux de conversion 4 fois supérieur à celui mesuré sur le trafic de recherche organique classique. Répartition publiée du trafic IA sur wordcount.com : ChatGPT 92,4 % des visiteurs, Perplexity 4,6 %, Gemini 2,7 %, Copilot 0,2 %. Déclaration d'inscriptions publiée côté Ahrefs : ChatGPT et Claude cumulent 21,7 % des sources déclarées, YouTube 18,0 %, Google 42,5 %. Étude citée dans l'article sur un échantillon d'environ 75 000 marques : les mentions de marque sur le web sont corrélées aux mentions dans les plateformes IA avec un coefficient r compris entre 0,66 et 0,71 selon la plateforme, contre des coefficients inférieurs à 0,33 pour les backlinks et le Domain Rating.**

**Limites.** Les chiffres proviennent des outils d'analytics et des enquêtes d'inscription d'Ahrefs sur son propre site wordcount.com, échantillon de taille et période de collecte non publiés dans l'article. L'article est publié par Ahrefs, qui vend les outils cités (Web Analytics, Brand Radar). Les chiffres sont propres à Ahrefs et ne sont pas généralisables au-delà du périmètre mesuré.

**Source.** Ahrefs, Louise Linehan, 6 octobre 2026 - https://ahrefs.com/blog/how-to-measure-ai-search-visibility/
