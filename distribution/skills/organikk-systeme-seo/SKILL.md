# Le système SEO d'Organikk

## Quand utiliser ce skill

Index du système SEO d'Organikk : les 3 workflows du bootcamp (mots-clés, rédaction/production, audit/alerting) et la doctrine SEO complète (passage ranking, entités, Needs Met, méthodo consolidée), plus le kit d'onboarding client.
TOUJOURS charger ce skill quand l'utilisateur demande « le workflow mots-clés », « le workflow de rédaction », « le workflow d'audit », « la doctrine SEO », « la méthode Organikk », « le kit client », ou quand il lance un chantier SEO long sans savoir par quel skill commencer.

Ce skill n'exécute rien. Il donne la carte du système et renvoie vers le bon fichier.

## Les 3 workflows

Un workflow est une suite d'étapes qui enchaîne plusieurs skills. Lis le fichier en entier avant de commencer.

| Besoin | Fichier |
|---|---|
| Partir d'une thématique et arriver à une liste de pages à produire | `.seokb/base/wiki/workflows/workflow-mots-cles.md` |
| Produire un article de la recherche à la publication | `.seokb/base/wiki/workflows/workflow-redaction-production.md` |
| Auditer un site et mettre en place le suivi | `.seokb/base/wiki/workflows/workflow-audit-alerting.md` |

## La doctrine

`wiki/doctrine/` : le wiki SEO — concepts (passage ranking, entités, Surprise Score), synthèses méthodo, fiches techniques (BERT, BM25, SGE…), décisions.

`raw/organikk/` : le kit d'onboarding client, la doctrine de production de contenu, les revues de presse.

`.seokb/base/wiki/AGENTS.md` : comment les pièces s'articulent entre elles.

## Par où commencer

| Skill | Ce qu'il fait |
|---|---|
| `seo-recherche-mots-cles` | Part d'une thématique, sort une liste qualifiée et priorisée |
| `seo-clustering-mots-cles` | Regroupe une liste brute en clusters — 1 cluster = 1 page |
| `audit-complet-v2` | Audit complet d'un site, livrable en dashboard HTML |
| `seo-brief-contenu` | Brief éditorial avec structure Hn |

## Règles qui traversent tout le système

- Aucun volume de recherche estimé. Un chiffre s'affiche avec sa source, ou ne s'affiche pas.
- Une observation mesurée n'est pas un frein démontré. Typer chaque information : FACT, HYPOTHESIS, ACTION.
- Les cas clients cités dans la doctrine sont anonymisés.
