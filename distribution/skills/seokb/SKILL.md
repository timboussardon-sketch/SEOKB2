# SEOKB2
Lire `.seokb/AGENTS.md` et `.seokb/base/wiki/index.md` pour retrouver les références.
Les connaissances communes résident dans `.seokb/base/` ; les données et livrables de l'élève restent dans `raw/` et `wiki/` du coffre.
Les skills sont dans `.claude/skills/`. Les anciennes automatisations personnelles de Tim ne sont pas installées.
Vérifier l'installation avec `python3 .seokb/runtime/doctor.py`.
Pour afficher le coffre : `python3 .seokb/runtime/dashboard.py --port 0` ; communiquer l'adresse imprimée après contrôle HTTP.
