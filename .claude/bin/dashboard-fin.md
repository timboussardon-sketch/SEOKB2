## Les commandes essentielles de Claude Code

### Démarrer un projet

`/init` : crée le fichier `CLAUDE.md` du projet. Claude le relira à chaque nouvelle session.

`/memory` : permet de consulter et modifier ce que Claude garde en mémoire pour le projet.

### Gérer la conversation

`/clear` : vide la conversation et repart de zéro.

`/compact` : résume la conversation actuelle pour libérer de la place sans perdre le contexte important.

`/context` : affiche l’espace utilisé et restant dans la conversation.

`/resume` : permet de reprendre une conversation précédente.

`/rewind` : revient à un point précédent et peut annuler les modifications faites depuis.

### Régler Claude Code

`/model` : change le modèle utilisé.

`/permissions` : choisit ce que Claude peut faire automatiquement et ce qui nécessite votre validation.

`/usage` : affiche votre consommation et les limites de votre forfait.

`/config` : ouvre les réglages de Claude Code.

`/help` : affiche la liste complète des commandes disponibles.

### Les raccourcis à connaître

`Échap` : arrête Claude pendant sa réponse.

`Échap` deux fois avec le champ vide : permet de revenir en arrière.

`Shift + Tab` : change de mode de travail, par exemple entre le mode normal et le mode plan.

`!` devant une commande : exécute directement cette commande dans le terminal. Claude voit ensuite son résultat.

`@` : permet de donner directement un fichier à Claude.

`Ctrl + C` deux fois : quitte Claude Code.
